# Personal AI recommendations: canonical user description

## Русский

Персональная модель не открывает файлы заново и не учится напрямую на их содержимом. Для каждой оценённой находки она использует только сведения, которые PrivacyAudit уже рассчитал во время обычного аудита: Exposure Score, размер и возраст файла, расширение, категории файла, каталога и сканера, количество совпадений ПДн, секретов и следов личности, признаки конфигурации учётных данных, архива и документа, а для медиа — лица, GPS, поля EXIF и серийный номер камеры. Оценённый объект истории приложений дополнительно передаёт только уже разобранные локальные метаданные Jump List: категорию приложения, источник Automatic/Custom, доступность цели, сохранение в меню, количество и давность взаимодействий, признак сетевого пути и совпадение с находкой аудита. Каждый снимок признаков связывается только с твоей оценкой 👍 или 👎; объекты без оценки в обучение не входят. Оценки, снимки признаков и веса модели остаются в твоём локальном профиле PrivacyAudit.

Обучение разрешено после минимум 20 оценок: не меньше 5 каждого типа, при этом меньший класс должен составлять хотя бы 20% всех оценок. Приложение переводит категории в числовые признаки, затем лёгкий локальный линейный классификатор учится находить сочетания, которые чаще сопровождаются твоими 👍 или 👎. Каждая находка или историческая ссылка получает отдельный Personal Attention Score от 0 до 100. Приложения сортируются по средней оценке трёх самых рекомендованных объектов; само приложение не используется как одна общая обучающая метка. Модель обновляется после 10 новых оценок или по твоей команде; модель с несовместимой схемой признаков не используется и должна быть обучена заново.

Например, если ты обычно отмечаешь интересными старые конфигурационные или текстовые находки с признаками ПДн и секретов, другая текстовая находка с похожим набором уже рассчитанных признаков может получить высокий персональный балл. Если в медиа ты чаще отмечаешь снимки с GPS, EXIF, лицами или признаками документа, такие изображения могут подняться в персональной сортировке. Если тебе интересны закреплённые, часто использовавшиеся или исчезнувшие исторические пути, похожие объекты могут подняться в «Истории приложений». Это только дополнительная рекомендация: она не меняет работу сканеров, не вызывает дополнительное чтение файлов и не заменяет оценки Exposure, ПДн, Secrets или Archive.

## English

The personal model does not reopen files or learn directly from their contents. For each rated finding, it uses only information PrivacyAudit has already calculated during the normal audit: Exposure Score, file size and age, extension, file/directory/scanner categories, counts of personal-data, secret and identity matches, credential-config, archive and document indicators, and—for media—faces, GPS, EXIF fields and camera serial data. A rated application-history object additionally contributes only local Jump List metadata already parsed by PrivacyAudit: application category, Automatic/Custom source, target availability, pinned state, interaction count and age, network-path status, and whether it matches an audit finding. Each feature snapshot is paired only with your 👍 or 👎; unrated objects are not training data. Ratings, feature snapshots and model weights remain in your local PrivacyAudit profile.

Training is allowed only after at least 20 ratings, including at least 5 of each kind, with the smaller class representing at least 20% of all ratings. The app converts categories into numeric indicators, then a lightweight local linear classifier learns which combinations more often accompany your 👍 or 👎. It assigns each finding or remembered object a separate Personal Attention Score from 0 to 100. Applications are ranked by the average of their three strongest object recommendations; an application itself is never used as one broad training label. The model is refreshed after 10 new ratings or on request; a model built with an incompatible feature schema is not used and must be trained again.

For example, if you usually rate old configuration or text findings with personal-data and secret indicators as interesting, another text finding with a similar set of calculated indicators may receive a high personal score. If you tend to rate media with GPS, EXIF, faces or document indicators as interesting, those images may rise in personal sorting. If you rate pinned, frequently used or missing historical paths as interesting, similar remembered objects may rise in Application history. This is only an extra recommendation: it does not change scanning, trigger extra file reads, or replace Exposure, Personal Data, Secrets or Archive scores.
